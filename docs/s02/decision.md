# S0.2 特权伴侣门槛决策

日期：2026-08-03

设备：Redmi `23078RKD5C` / Android 13 / MIUI 14

决策：**`SHIZUKU_POC_FEASIBLE`**

## 决策含义

- Standard 路径仍为 No-Go：普通应用进程无法满足 MIUI 14 的实时可靠性门槛。
- ADB/shell 上界通过：证明 shell 执行面本身具备达到门槛的能力。
- Kotlin + Shizuku UserService 通过：证明该执行面可由独立 Kotlin 原型承载，而不是只能依赖电脑端循环。
- 原计划 S1 不自动恢复；先重定 Advanced 架构、安全协议、失效降级和发布渠道。
- 本决策不是消费者发布 Go，也不授权真实第三方包的强制停止、挂起、禁用或其他持久动作。

100/100 指标的 Wilson 95% 区间为 96.30%-100%。允许流程 `0/15` 的上界仍高，必须在后续扩大样本，不能据此宣称发布级低误判。

## 已验证安全边界

- 只处理一个固定测试来源和一个固定测试目标；
- 每个序列最多执行一次 Back；
- 不使用 Home 作为伴侣动作；
- 不执行 force-stop、suspend、disable 或设备管理操作；
- 不使用 Root 或 Device Owner；
- 普通 S0 App 在所有 S0.2 运行中保持未武装；
- 原始时间线只保存在本机，公开仓库仅保留聚合报告。
