# S0.7 设备状态与多窗口上下文失效决策

状态：**通过，决策为 `S07_DEVICE_STATE_GATE_PASSED`**

设备：Redmi `23078RKD5C` / Android 13 / MIUI 14

版本：`0.0.7-s07` / UserService v6

日期：2026-08-09

## 决策

允许继续下一项 Advanced S0 架构与安全验证。正式矩阵中的最近任务 `5/5`、分屏 `5/5` 和息屏/锁屏恢复 `1/1` 均完整记录来源上下文失效，之后目标检测和 Back 请求均为 0；独立全屏正向对照的检测、Back、离开和返回均为 `10/10`。

此决策不改变 Standard S0 No-Go，不授权消费者发布、真实第三方应用控制或 L3-L5 持久动作。

## 缺陷与修复判定

修复前的单前台模型在分屏中丢失窗口集合信息，会话 `9957ab8bb5ba41bda9f8d97b1e555442` 对同时 resumed 的目标执行了 1 次 Back。该路径已由失败摘录固定。

采用的修复只收紧动作前置条件：完整解析 top-resumed 集合；多前台立即标记歧义并使来源失效；息屏/锁屏立即使来源失效；最终动作同时复核 owner、设备交互、锁屏、前台集合、目标、能力、规则快照和租约。普通全屏切换的瞬时前台空洞采用 500 ms 持续门，正式正向对照证明合法路径保持 `10/10`。
