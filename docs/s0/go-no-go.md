任一安全否决项不通过，不得给出 Go。

## 能力结论

### 稳定

- 在本机解除电池限制、允许自启动并由用户明确启动前台服务后，静置 35 分钟仍保持前台保活状态；
- 6 秒来源间隔的记录模式稳定 100 次中，组合实时事件与候选均为 100/100；
- 无障碍主信号在稳定批次为 100/100，候选延迟 P95 110 ms；
- 重连后历史 UsageStats 事件只记录为预热、不驱动候选；随后单次跳转为 1/1；
- 本轮未观察到安全违规、ANR 或广播超时。

### 不稳定但可工程化缓解

- 约 2.1 秒节奏的短间隔压力 10 次中，仅 2/10 在 500 ms 内到达；其余事件在 MIUI Greeze 解冻后约 48-59 秒才出现。稳定基线改用 6 秒间隔可以避免本机 5 秒冻结窗口，但真实应用的突发连续拉起仍是明确风险；
- UsageStats 在稳定批次只有 49/100 实时到达、最终 100/100 到达，不能作为单独的实时动作依据；
- 前台服务、自启动和电池无限制是当前 MIUI 基线条件，仍需验证重启、用户划掉任务、长待机与电量影响。

### 公开 API 下不可实现

- 无法获得来源应用发出的原始 Intent；
- 无法获得 Android 公共 API 提供的权威“调用者 → 目标”调用链；
- 普通无 Root 模式无法在 `startActivity()` 之前通用拦截。
